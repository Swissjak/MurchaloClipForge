Privacy Policy

Effective August 28, 2026

MurchaloClipForge is a locally operated Windows desktop application. It does not ask for or store your TikTok password.

1. Information processed

The application may process video and audio files selected by the user, speech transcripts generated from those files, source attribution entered or recovered from source metadata, publication captions, schedules, and available performance statistics.

2. TikTok account data

When a user connects TikTok, authorization is completed through TikTok OAuth. The application may receive an access token, refresh token, TikTok account identifier, account display information, available publishing settings, publication status, and statistics permitted by the scopes approved by the user.

3. Local storage

Project files, schedules, captions, attribution, publication identifiers, and statistics are stored on the user's device. TikTok user tokens are encrypted for the current Windows account using Windows data protection. Application credentials supplied by the operator remain on that device.

4. External transfers

Selected videos and their approved captions are transferred to TikTok only when the user confirms an immediate publication or adds the video to the local publishing schedule. TikTok processes that information under its own privacy policy. Downloaded source content may also be obtained from a source platform at the user's direction.

5. Attribution

The application is designed to retain the original creator's name and source URL in publication metadata. Users remain responsible for having the rights and permissions required to process and publish content.

6. Data sharing and sale

MurchaloClipForge does not sell personal information. The application does not operate an advertising profile or send local project data to an independent MurchaloClipForge analytics server.

7. Retention and deletion

Local data remains until the user deletes the corresponding project files or application data. Users can revoke MurchaloClipForge access from their TikTok account settings and remove locally stored authorization data.

8. Security

Reasonable local safeguards are used, including Windows user-bound token encryption. No storage or transmission system can be guaranteed completely secure.

9. Children

The application is not directed to children under the minimum age required to use TikTok in their jurisdiction.

10. Changes

This policy may be updated when application behavior or platform requirements change. The effective date above identifies the current version.

11. Contact

Privacy questions may be submitted through the public issue tracker of the official MurchaloClipForge GitHub repository.
